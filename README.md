# Rueda Libre

Sitio estático para presentar los servicios de alquiler de bicicletas y recorridos guiados de Rueda Libre en Medellín. El proyecto usa clases de utilidad de Tailwind CSS con un enfoque mobile first; no utiliza Bootstrap ni estilos en línea.

## Páginas

- `index.html`: presentación, servicios, beneficios y ubicación.
- `paginas/tarifas.html`: precios de alquiler y recorridos guiados.
- `paginas/reservas.html`: formulario de solicitud de reserva con validación HTML.

## Tecnologías y recursos

- HTML semántico.
- Tailwind CSS mediante su CDN, con colores y tipografías de marca configurados en cada página.
- Imágenes locales en `img/` y tipografías de Google Fonts.

Para ver el sitio localmente, abre `index.html` en un navegador con conexión a internet. La hoja de utilidades de Tailwind y las tipografías se cargan desde sus respectivos servicios externos.
